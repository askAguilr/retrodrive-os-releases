# RetroDrive OS vehicle store

Public, account-free delivery of the Suzuki Samurai and Mazda CX-5 vehicle packages for RetroDrive OS.

The store files use authenticated encryption and are opened by the app. They include each vehicle's video, static fallback image, duration, integrity metadata and headlight calibration. This deters casual direct reuse; it is not DRM because a working app must contain the means to decode its assets.

No application source, account credentials, Mapbox access token or signing keys are published here. No APK release is currently published in this repository. Application distribution is separate while the corresponding-source licensing requirements for its included engines are resolved.
